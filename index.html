Problem 1(b.i): Machine Shutdown Constraint

A preventive maintenance window requires machine $\alpha^*$ to be fully clear by time $t^*$.

Exact Class Solution Formulation:
$X_{j\alpha^*} + p_{j\alpha^*} \le t^* \quad \forall j \in \{1, \dots, J\}$

Problem 1(b.ii): Perishable Dairy Factory Sandbox

Minimize total earliness & tardiness costs using completion time on last machine $l_j$.

Objective Function $\min \sum_{j=1}^{J} (E_j \cdot q_j + T_j \cdot u_j)$: 0.00 €
